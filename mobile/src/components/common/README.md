# Common Components

Reusable UI components used throughout the application.

## Planned Components

- **Button** - Standard button with variants (primary, secondary, danger, ghost)
- **IconButton** - Circular icon button (for panic button, record button)
- **Input** - Text input with validation states
- **Card** - Content container with optional header/footer
- **Badge** - Tag/label display
- **Modal** - Overlay modal dialogs
- **Toast** - Notification toasts
- **LoadingSpinner** - Activity indicator
- **EmptyState** - Placeholder for empty lists
- **ErrorBoundary** - Error catching wrapper
